# ANN算法性能分析报告

## 测试环境
- 编译器: GCC
- 编译选项: -O3 -march=native
- 测试数据: DEEP100K (100K base vectors, 2000 queries)
- 向量维度: 96

## 性能指标说明
- **指令数 (Instructions)**: 执行的CPU指令总数
- **周期数 (Cycles)**: CPU执行周期总数
- **CPI (Cycles Per Instruction)**: 每指令周期数，越低越好
- **L1缓存命中率**: L1数据缓存命中率
- **LLC缓存命中率**: 最后一级缓存命中率
- **IPC (Instructions Per Cycle)**: 每周期指令数，越高越好
